# Data Structure Lab (CIS 122L)

This repository contains all the C programs implemented during the Data Structure Lab course (CIS 122L) at Daffodil International University (DIU). The programs are organized week-by-week based on the official lab manual.

## Course Information

*   **Course Title:** Data Structure Lab
*   **Course Code:** CIS 122L
*   **Level/Term:** Level 1 Term 2
*   **Preferred Language:** C/C++

---

## 📂 Repository Structure & Program Index

### [Week 01](./Week%2001) : Array Operations - Insertion
*   `01. Insert in array.c` - Insert an element into an array at a specific position.
*   **Practice Problems:**
    *   `I. Insert multiple elements.c` - Insert multiple elements at specific positions.
    *   `II. Insert ascending array.c` - Insert an element maintaining sorted order.

### [Week 02](./Week%2002) : Array Operations - Deletion & Updation
*   `01. Delete element.c` - Delete an element in an array at a specific position.
*   `02. Update element.c` - Update an element in an array at a specific position.
*   **Practice Problems:**
    *   `I. Delete all same values.c` - Delete all occurrences of a specific value.
    *   `II. Update even elements by 5.c` - Update all even elements by adding 5.

### [Week 03](./Week%2003) : Array Operations - Splitting
*   `01. Split array (even-odd).c` - Split an array into two arrays based on odd and even numbers.
*   **Practice Problems:**
    *   `I. Split array (%3).c` - Split an array into multiples of 3 and non-multiples of 3.
    *   `II. Split array (-ve, +ve).c` - Split an array into positive and negative numbers.

### [Week 04](./Week%2004) : Array Operations - Merging
*   `01. Merging two sorted arrays.c` - Merging two sorted arrays into one sorted array.
*   **Practice Problems:**
    *   `I. Merging and Deleting duplicates.c` - Merge two arrays and remove duplicate elements.
    *   `II. Merging 3 to 1 and sorting.c` - Merge three sorted arrays into one sorted array.

### [Week 05](./Week%2005) : Stack Operations
*   `01. Stack function (PUSH-POP).c` - Insert an element into a stack (PUSH) and remove an element from a stack (POP).
*   **Practice Problems:**
    *   `I. Stack using functions.c` - Implement stack using functions for PUSH, POP, and DISPLAY.
    *   `II. Reverse array by stack.c` - Reverse an array using a stack.

### [Week 06](./Week%2006) : Queue Operations
*   `01. Queue (Enqueue-Dequeue).c` - Insert an element into a queue (Enqueue) and delete an element from a queue (Dequeue).
*   **Practice Problems:**
    *   `I. Front and Rear element.c` - Find the front and rear elements of a queue.
    *   `II. Count total element.c` - Count the total number of elements currently in the queue.

### [Week 07](./Week%2007) : Linked List - Traversing
*   `01. Traversing linked list.c` - Traversing a singly linked list.
*   **Practice Problems:**
    *   `I. Count nodes.c` - Count the number of nodes in a linked list.
    *   `II. Sum of node values.c` - Find the sum of all node values in a linked list.

### [Week 08](./Week%2008) : Linked List - Searching
*   `01. Searching singly linked list.c` - Searching for a value in a singly linked list.
*   **Practice Problems:**
    *   `I. Search by index.c` - Search for a node by its position index.
    *   `II. Count occurrences.c` - Count occurrences of a specific value in the linked list.

### [Week 09](./Week%2009) : Linked List - Splitting
*   `01. Splitting by position.c` - Splitting a singly linked list based on a specified position.
*   `02. Splitting by condition.c` - Splitting a singly linked list based on a specified condition.
*   **Practice Problems:**
    *   `I. Split odd-even position.c` - Split a linked list into odd and even positioned nodes.
    *   `II. Separate values greater than 50.c` - Separate nodes with values greater than 50 into a new linked list.

### [Week 10](./Week%2010) : Linked List - Merging
*   `01. Merge two linked lists.c` - Merge two simple linked lists into a single linked list.
*   **Practice Problems:**
    *   `I. Merge sorted linked lists.c` - Merge two sorted linked lists into one sorted linked list.
    *   `II. Merge alternately.c` - Merge two linked lists alternately (node-by-node).

### [Week 11](./Week%2011) : Linked List - Insertion
*   `01. Insertion all positions.c` - Inserting nodes at the beginning, middle, and end of a simple linked list.
*   **Practice Problems:**
    *   `I. Insert at given index.c` - Insert a node at a given position index.
    *   `II. Insert in sorted order.c` - Create a sorted linked list by inserting nodes in sorted order.

### [Week 12](./Week%2012) : Linked List - Deletion
*   `01. Deletion all positions.c` - Deleting nodes from the beginning, middle, and end of a linked list.
*   **Practice Problems:**
    *   `I. Delete specific value.c` - Delete all nodes containing a specific value.
    *   `II. Delete entirely.c` - Delete a linked list completely (free all nodes).

### [Week 13](./Week%2013) : Binary Search Tree (BST)
*   `01. Insert in BST.c` - Inserting nodes into a binary search tree.
*   **Practice Problems:**
    *   `I. Min and Max in BST.c` - Find the minimum and maximum value in a BST.
    *   `II. Count total and leaf nodes.c` - Count total nodes and leaf nodes in a BST.

### [Week 14](./Week%2014) : Searching Algorithms
*   `01. Linear Search.c` - Linear searching algorithm.
*   `02. Binary Search.c` - Binary searching algorithm.
*   **Practice Problems:**
    *   `I. Compare execution time.c` - Compare the execution time of linear and binary search for the same dataset.
    *   `II. Find all indices (Linear).c` - Find all indices of a given value in an array using linear search.

### [Week 15](./Week%2015) : Sorting Algorithms
*   `01. Insertion Sort.c` - Insertion sort algorithm.
*   `02. Selection Sort.c` - Selection sort algorithm.
*   `03. Bubble Sort.c` - Bubble sort algorithm.
*   **Practice Problems:**
    *   `I. Bubble sort (Descending).c` - Sort an array in descending order using bubble sort.
    *   `II. Selection sort (Strings).c` - Sort an array of strings using selection sort.

### Final Challenge Problems
*   `1. Stack-Queue Menu.c` - Menu-driven C program to perform insertion, deletion, and display in both stack and queue.
*   `2. BST Depth.c` - Search a node in BST recursively and display its depth/level.
*   `3. Doubly Linked List.c` - Create and traverse a doubly linked list.
*   `4. Intersection of Linked Lists.c` - Find the intersection of two linked lists.
*   `5. Array Operations.c` - Analyze a 1D array to count frequency, identify duplicates, and show unique array.
